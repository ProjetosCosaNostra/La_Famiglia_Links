PRIVACY · CURRENT STAGING BUILD

The browser keeps the small amount of state this preview needs.

This policy describes the current staging experience. If a future public release introduces hosted analytics, accounts, forms or other data collection, the policy must be updated before that feature is enabled.

01

Browser-local state

The current experience uses browser storage for comparison selections, buying-guide checklist progress and local campaign events. These values are stored in the browser used for the staging experience.

02

Current analytics boundary

The staging build does not intentionally send its BlackGold campaign event log to a third-party analytics endpoint. Campaign impressions, gate events and verified retailer-click events are designed to remain local in this build.

03

External retailers

If a future verified Retailer Gate sends a shopper to an external retailer, that destination operates under its own privacy practices. BlackGold Beauty Finds cannot control data collection performed by the retailer or affiliate network after the shopper leaves this site.

04

Clearing local state

Comparison selections and guide progress can be removed by clearing browser site data. The internal Campaign Operations page also includes a control for clearing the local BlackGold event log.

05

No account system in this build

The current static staging experience does not provide a BlackGold customer account, password database or profile system.

06

Policy changes

Any public feature that materially changes data handling should be accompanied by a policy update and a new verification date before release.

STAGING NOTICE

This page describes the build that exists now.

It does not promise that future versions will never use analytics or other services. It requires those changes to be disclosed before activation.
